4) Carnet de voyage — jour par jour

Jour 1 — Vendredi 12 juin • Arrivée à Vágar
Zone : Vágar (Sørvágur / Miðvágur)

Planning

  • 18:40 • Arrivée à FAE (Vágar).
  • 19:10–19:40 • Récupération voiture + route vers Sørvágur/Miðvágur (≈ 5–15 min).
  • 20:30 • Dîner simple + balade port de Sørvágur (si météo).

Must see

  • Première lumière sur le fjord / port de Sørvágur.

Spots photo

  • Port de Sørvágur : reflets + bateaux.
  • Vue au coucher du soleil depuis les hauteurs (si ciel dégagé).

Restaurants / bars (proches)

  • Option “sur le pouce” près de l’aéroport / villages : demander à l’hébergement (horaires variables).

Conseils

  • Prévoir une marge pour récupérer la voiture (bagages + formalités).
  • Si arrivée tardive : vérifier arrivée autonome à l’hébergement.
Carte (hébergement zone) : Google Maps (Vágar Airport)
Jour 2 — Samedi 13 juin • Mykines (option) + Gásadalur → Tórshavn
Zone : Vágar → Streymoy (Tórshavn)

Planning

  • Matin (option A) • Ferry Sørvágur → Mykines (selon météo) + rando (oiseaux / falaises).
  • Alternative (option B) • Si Mykines annulée : roadtrip Vágar (Bøur → Gásadalur → Múlafossur).
  • Fin d’après-midi • Route vers Tórshavn (≈ 1h) + check-in.
  • Soir • Découverte du port + vieille ville.

Must see

  • Múlafossur (Gásadalur).
  • Panorama de Bøur (Tindhólmur).

Randonnée / balade

  • Tracé Mykines : Billets ferry (mykines.fo)
  • Accès Mykines (infos) : Visit Vágar – transport

Spots photo

  • Múlafossur (falaises + cascade).
  • Bøur (vue mer + rochers).
Photo : Wikimedia Commons (CC BY-SA 4.0)

Restaurants (Tórshavn)

  • Dîner “local moderne” : Ræst (réservation conseillée).
  • Seafood : Barbara Fish House (réservation conseillée).

Liens cartes

  • Bøur : Google Maps
  • Gásadalur : Google Maps
  • Tórshavn : Google Maps

Conseils

  • Mykines : traversée possible uniquement si météo OK (vent/mer).
  • Partir tôt si vous voulez Mykines + Gásadalur le même jour.
Jour 3 — Dimanche 14 juin • Streymoy nord : Saksun → Tjørnuvík → Eiði
Zone : Streymoy (boucle depuis Tórshavn)

Planning

  • Matin • Route vers Saksun + balade lagune/val.
  • Midi • Direction Tjørnuvík (plage, point de vue).
  • Après-midi • Eiði : viewpoint “Risin & Kellingin” + Fossá waterfall sur le chemin du retour.
  • Soir • Retour Tórshavn + dîner.

Must see

  • Saksun (lagune + maisons toits d’herbe).
  • Risin & Kellingin (Eiði) au coucher si ciel.

Randonnée / balade (Wikiloc)

  • Trails autour de Saksun : Wikiloc (Saksun)

Spots photo

  • Saksun : panorama vallée + lagune.
  • Tjørnuvík : plage + falaises.
  • Eiði : mer + stacks (Risin/Kellingin).

Restaurants (Tórshavn)

  • Poisson : Barbara Fish House
  • Sushi/poisson : etika

Bars / ambiance

  • Centre/port : pubs & bars autour de la marina (idéals en fin de journée).

Liens cartes

  • Saksun : Google Maps
  • Tjørnuvík : Google Maps
  • Eiði viewpoint : Google Maps

Conseils

  • Routes étroites vers Saksun : rouler cool, croisements fréquents.
  • Prévoir coupe-vent : zones exposées.
Jour 4 — Lundi 15 juin • Eysturoy : Gjógv + belvédères
Zone : Eysturoy (boucle depuis Tórshavn)

Planning

  • Matin • Route vers Gjógv (village + gorge).
  • Midi • Pause café + snack au village.
  • Après-midi • Petite rando falaises (selon accès/conditions) + viewpoints sur la route (Funningur / Eiði).
  • Soir • Retour à Tórshavn, balade Tinganes.

Must see

  • La gorge de Gjógv + vues falaises.
  • Tinganes (vieux quartier, maisons rouges).

Randonnée / balade (Wikiloc)

  • Trails Gjógv : Wikiloc (Gjógv)

Spots photo

  • Gjógv : gorge + bord de mer.
  • Tinganes : ruelles + toits d’herbe.

Restaurants (Tórshavn)

  • Expérience : Ræst (à réserver).
  • Alternative : etika

Shopping local

  • Centre de Tórshavn : boutiques laine/handmade, souvenirs nordiques.

Liens cartes

  • Gjógv : Google Maps
  • Tinganes : Google Maps

Conseils

  • Certains sentiers peuvent demander un accès payant/privé : respecter les panneaux.
  • Prévoir “plan B” si brouillard (musées/ville).
Jour 5 — Mardi 16 juin • Transfert vers Klaksvík + découverte
Zone : Streymoy → Eysturoy → Borðoy (Klaksvík)

Planning

  • Matin • Check-out Tórshavn.
  • Route vers Klaksvík (≈ 1h15–1h45 selon arrêts).
  • Après-midi • Check-in + balade port/ville + point de vue sur le fjord.
  • Soir • Dîner à Klaksvík, préparation Kalsoy (ferry demain).

Must see

  • Port de Klaksvík au “golden hour”.

Spots photo

  • Front de mer + montagnes en arrière-plan.

Restaurants (Klaksvík)

  • Restaurant de l’hôtel (pratique) : Hotel Klaksvík

Liens cartes

  • Klaksvík : Google Maps
  • Terminal ferry Kalsoy : Google Maps

Conseils

  • Préparer sacs légers pour Kalsoy (rando + vent).
  • Se présenter au ferry tôt (places voitures limitées).
Jour 6 — Mercredi 17 juin • Kalsoy : Kallur Lighthouse
Zone : Kalsoy (aller/retour depuis Klaksvík)

Planning

  • Matin • Ferry Klaksvík → Kalsoy (à choisir selon horaires du jour).
  • Transfert interne (bus/taxi ou voiture si embarquée) vers Trøllanes.
  • Randonnée • Kallur Lighthouse (2–3h aller/retour selon pauses).
  • Après-midi • Retour ferry + dîner à Klaksvík.

Must see

  • Phare de Kallur + crêtes (si visibilité).

Randonnée (Wikiloc)

  • Trace : Kallur Lighthouse (Wikiloc)

Spots photo

  • Panorama “carte postale” sur le phare.
  • Crêtes herbeuses (attention falaises).
Photo : Wikimedia Commons (CC BY-SA 4.0)

Liens cartes

  • Trøllanes : Google Maps
  • Kallur Lighthouse : Google Maps

Conseils sécurité

  • Falaises exposées : ne pas s’approcher du bord, surtout avec vent + sol humide.
  • Chaussures adhérentes + coupe-vent.
Jour 7 — Jeudi 18 juin • Retour Vágar + Trælanípa (Sørvágsvatn)
Zone : Borðoy → Vágar

Planning

  • Matin • Départ Klaksvík → Vágar (≈ 1h30–2h selon arrêts).
  • Début aprem • Randonnée Trælanípa / Sørvágsvatn (2–4h selon rythme).
  • Fin aprem • Installation près de l’aéroport + dernier sunset.
  • Soir • Dîner de clôture.

Must see

  • Le point de vue “lac au-dessus de l’océan”.

Randonnée (Wikiloc)

  • Trace : Trælanípa (Wikiloc)

Spots photo

  • Trælanípa : falaise + vue “illusion d’optique”.
  • Dernières lumières sur Vágar.

Liens cartes

  • Départ rando (zone) : Google Maps
  • Lac Sørvágsvatn : Google Maps
  • Aéroport FAE : Google Maps

Conseils

  • Prévoir météo et visibilité : c’est le “gros” spot photo, à faire au bon créneau.
  • Hydratation + snacks (vent donne faim).
Jour 8 — Vendredi 19 juin • Départ
Zone : Vágar → Paris

Planning

  • 09:45–10:30 • Check-out + route aéroport.
  • Retour voiture + enregistrement.
  • 12:20 • Vol RC424 (FAE → CDG) • Arrivée 16:00.

Conseils

  • Prévoir marge (météo + restitution voiture + carburant).

Derniers achats

  • Souvenirs laine/handmade à Tórshavn si vous avez gardé du temps la veille.
