Jour par jour (détails opérationnels)

Chaque jour : une version A (météo correcte) + une version B (météo dégradée). Ajustez selon le vent et les nuages.

Jour 1 — Ven 12/06 : Arrivée à Vágar → Tórshavn
Pick-up voiture 19:15 • route vers Tórshavn • installation
ObjectifAtterrir, récupérer la voiture, s’installer sans stress.

Plan A

  • Récupération voiture (photos + vérifs).
  • Trajet vers Tórshavn, stop rapide si ciel dégagé : point de vue proche (sans détour).
  • Installation + promenade port / centre (Tinganes si accessible).

Plan B (fatigue / pluie)

  • Trajet direct + courses (supermarché) + dîner simple.
  • Préparer le programme du lendemain et les snacks/pique-niques.
Checklist arrivée : eau, snacks, adaptateur, couches chaudes, cartes/CB, réservation Airbnb, heure check-in.
Jour 2 — Sam 13/06 : Streymoy (côtes & villages)
Base Tórshavn • route modérée • paysages “carte postale”

Plan A (météo ok)

  • Matin : route vers Vestmanna (falaises/points de vue selon accès).
  • Midi : snack/pique-nique abrité (prévoir coupe-vent).
  • Après-midi : Saksun (lagune/village) ou Tjørnuvík (plage) selon temps.
  • Retour : dîner à Tórshavn.

Plan B (vent fort / plafonds bas)

  • Tórshavn : cafés + petites boutiques + musées/visites (centre).
  • Courte balade côtière facile si fenêtre météo (30–60 min).
Routes étroites : privilégier les arrêts “safe” (parking/élargissement) plutôt que les arrêts improvisés.

Randonnées (choix pragmatique)

Objectif : 1 rando “signature” + 2–3 balades faciles. Ne pas surcharger.

  • Sørvágsvatn / Trælanípa (Vágar) : rando phare (partir tôt).
  • Gjógv (Eysturoy) : balade facile + paysages.
  • Balades côtières : choisir selon vent et visibilité.
Équipement minimum : veste imperméable, pantalon pluie, gants fins, bonnet, bonnes chaussures, couche chaude.

Règles sécurité (vent / météo)

  • Éviter crêtes/falaises si rafales ou brouillard.
  • Garder une marge : demi-tour si la visibilité se dégrade.
  • Informer le groupe du plan (durée, retour, dernier départ acceptable).
Les falaises aux Féroé ne pardonnent pas : pas de “photo au bord”, surtout par vent.

Infos pratiques — conduite

  • Routes étroites : conduite souple, attention aux moutons et aux arrêts photo.
  • Tunnels : possibles péages/consignes. Anticiper les entrées/sorties.
  • Carburant : faire le plein avant les longues boucles et avant le retour voiture.
Conseil : fixez une “heure limite” de départ retour chaque jour pour respecter ≤4h de route.

Infos pratiques — météo

  • Météo changeante : superposer les couches, protéger l’électronique.
  • Plan B quotidien : ville/cafés + balades courtes.
  • Fenêtres météo : profiter vite, sans attendre “le ciel parfait”.
Meilleure stratégie : programme “modulaire” (spots proches) plutôt qu’une boucle trop longue.

Checklist “matin”

  • Regarder le vent + pluie (appli météo) + visibilité.
  • Choisir Plan A ou Plan B.
  • Préparer pique-nique / eau / thermos.
  • Charger : téléphones, powerbank, appareil photo.
  • Vêtements : imper + couche chaude + bonnet/gants.

Checklist “soir”

  • Ravitaillement snacks / petit-déj si besoin.
  • Préparer départ du lendemain (heures, trajets, ferry si prévu).
  • Réserver resto si nécessaire.
  • Sauvegarder photos.
Mode d’emploi : ce carnet est volontairement “offline-friendly”. Ajoutez vos liens (Maps/restos) au fil de l’eau.
